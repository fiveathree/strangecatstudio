# 規格：SEO 收尾、前台商品搜尋、首頁推廣區

> 一個功能一個檔。設計、實作、驗收都只看這個檔，各自填自己的章節，不改別人的章節。

> 狀態：開發中（本機完成，未上線）
> 建立：2026-10-18　最後更新：2026-10-18

---

## 1. 需求（用戶）

- 目的：讓客人搜得到網站、在現貨頁找得到商品、在首頁看到目前主推的東西。
- 原則：沿用現有頁面、商品資料與篩選程式；不加搜尋 API、資料庫、框架、套件或廣告管理系統。
- 範圍內：
  1. **SEO 收尾（程式部分）**：更新 `sitemap.xml`；加入 Google Search Console 的驗證標籤；檢查各頁標題、描述、圖片替代文字與站內連結。
  2. **前台商品搜尋**：現貨頁加一個搜尋框，輸入關鍵字（例如「貓咪」「玻璃鑽石」「項鍊」），按商品名稱、規格說明、主石、類別即時篩選，與現有篩選按鈕同時生效，顯示結果數量與「找不到」提示。
  3. **首頁推廣區**：首頁一個推廣區（一張圖、一句標題、一句說明、一個按鈕連結），沿用現有設計與相片。
- 範圍外（這次不做）：每件貨品的獨立網址放進 sitemap、預先產生商品頁 HTML、AI 搜尋或推薦、多個輪播 Banner、Google Ads／Instagram 廣告、金流與物流。
- 要你或老闆做（不是程式）：
  - 建立 GA4 資源並把評估 ID（`G-` 開頭）給我，我填入 `js/config.js`。
  - Google Search Console 新增「網址前置字元」資源，選「HTML 標記」驗證，把那一行 `<meta name="google-site-verification" ...>` 給我（這不是密碼，可以貼）；驗證後提交 `sitemap.xml`。
  - 老闆登記台南、高雄兩間工作室的 Google 商家檔案。

## 2. 驗收標準（用戶確認後才開始）

- [ ] AC1 搜尋：在現貨頁輸入「貓」，只顯示名稱、規格、主石或類別含「貓」的商品；結果數量同步更新；沒有結果時顯示「找不到」提示與「顯示全部作品」（清除搜尋與篩選）。
- [ ] AC2 搜尋與篩選同時生效：例如選「戒指」再輸入「玻璃」，只顯示同時符合的商品；清空搜尋框後回到只按篩選。
- [ ] AC3 搜尋不分大小寫、忽略前後空白；手機寬度（375px）搜尋框可以直接輸入，不出現橫向捲動。
- [ ] AC4 推廣區：首頁顯示一個推廣區，按鈕連到指定頁面；手機與桌面都正常；黑色與淺色版顏色都正確。
- [ ] AC5 字型：新加的中文字都以 Noto 字型顯示（字型檔已重新產生，或新字本來已在字型檔內）。
- [ ] AC6 SEO：`sitemap.xml` 的 `lastmod` 為實際更新日期、只列真正的公開頁；Search Console 驗證標籤在首頁 `<head>`（等你提供）。
- [ ] AC7 不影響現有功能：`node --experimental-sqlite booking/test.mjs` 通過；現貨頁的篩選、加入購物車、貨品頁照常。
